常见问题

能导出 MIDI 或分轨吗？

不能。当前 MiniMax Music 只返回整曲 MP3。拍号等参数会写入项目元数据，模型不保证遵守。

积分怎么扣？

提交时预留，成功结算，失败或排队中取消则退回。下载不扣生成积分。

可以真实付款升级吗？

不能。套餐价格是 PRD 示例，本环境只发放演示积分，没有支付 webhook。

模型用量与费用

音乐生成默认按 RunningHub 账号计费（MiniMax Music 约 ¥0.8/次）；Qwen 副驾按百炼账号计费。本平台不提供共享账号。生成前会提醒你确认调用。

本地密钥安全

密钥仅写入项目根目录的 .env 文件，不下发到浏览器，也不会回显。不要把 .env 提交到 Git 或发送到聊天中。Qwen 用百炼 Key；音乐可用 RunningHub Key 或百炼 Fun-Music。作品授权请以模型服务商当期条款为准。
